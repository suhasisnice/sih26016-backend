# in alembic/versions; nothing calls create_all() any more. The container

# see the Dockerfile for why the image needs cmake/g++ to build it. Pulls
# in dlib>=19.7 and face-recognition-models as transitive deps, compiled
# from source; there is no prebuilt wheel for this base image.
#
# VERIFY ON FIRST BUILD: face-recognition itself has not been updated
# since 2020, and numpy/Pillow below are pinned to what was current when
# this was written (Sept 2026), not to anything actually run against
# dlib's aged bindings. If the image fails to build or `import
# face_recognition` errors at runtime, the fix is almost certainly numpy
# ABI: drop to an older numpy 1.26.x or 2.0.x line and rebuild.
